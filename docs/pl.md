# Instrukcja rozwoju

Początkowo Windows. Przed zapisem flash zidentyfikuj port COM i rozmiar pamięci, odczytaj całą pamięć dwukrotnie i porównaj SHA-256. Kopie przechowuj poza repozytorium. Osobno sprawdź ekran, dotyk, Wi-Fi, RTC, akumulator i SHT30 przed włączeniem OTA. Wydania wymagają testów sprzętowych.

Architektura: niezależne źródła danych, wspólny model danych, renderer e-ink, trwała konfiguracja i zarządzanie energią. Oznaczamy nieaktualne dane. ICMP: trzy próby.
