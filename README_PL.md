# M5Paper MultiPanel

[English](README.md) | [Wiki](https://github.com/sp7uto/m5paper-multipanel/wiki)

Modułowy panel e-ink dla M5Paper v1.1. Niezależny projekt towarzyszący LilyGO T-Display S3.

**Status:** pre-alpha, bez zweryfikowanego firmware. Najpierw kopia flash pod Windows, następnie testy sprzętu.

## Moduły

SYSTEM, HOME, METEO, NETWORK (IPv4, IPv6, DNS, ICMP z trzema próbami), APRS, SENSOR, Home Assistant, RADIO, POWER.

Dokumentacja PL/EN, Wiki, Pages, USB i docelowo OTA. Nie publikujemy kopii flash ani sekretów.
