# M5Paper MultiPanel

[Polski](README_PL.md) | [Wiki](https://github.com/sp7uto/m5paper-multipanel/wiki)

Modular ESP32 e-paper dashboard for M5Stack M5Paper v1.1 — METEO, NETWORK, APRS, Home Assistant and amateur radio. Independent companion to the LilyGO T-Display S3 project.

**Status:** pre-alpha; hardware tests and factory flash backup pending. No validated firmware release.

## Roadmap

0.1 SYSTEM · 0.2 METEO · 0.3 NETWORK · 0.4 APRS · 0.5 SENSOR · 0.6 HA · 0.7 RADIO · 0.8 POWER · 0.9 integration · 1.0 stable.

Windows-first USB development; OTA planned. Documentation, Wiki and GitHub Pages in English and Polish. Never publish credentials or factory flash backups.
